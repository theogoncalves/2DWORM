# 2DWORM
2D-WORM is the browser-native, install-free program for chemists, biochemists and materials scientists — bridging the gap between atomic drawings, biological structures and crystalline materials. Build, read and edit molecular and periodic geometry, inspect orbitals and densities, sketch in 2D, and hand the result straight to your solver — from a laptop, a tablet, a phone, or an immersive Virtual Reality (VR) headset.
